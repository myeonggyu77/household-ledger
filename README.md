# household-ledger (가계부)

수입·지출·계좌·예산·정기거래를 관리하는 개인용 가계부입니다. 편한가계부와 비슷한 느낌으로,
서버 없이 브라우저 `localStorage`에만 데이터를 저장하는 단일 HTML 파일 PWA입니다.

## 실행 방법
`index.html`을 열거나, GitHub Pages로 배포하면 홈 화면에 앱처럼 설치할 수 있어요.

## 기능
- 홈: 이번 달 지출 top5, 예산 알림, 최근 거래
- 달력: 날짜별 수입/지출 확인 및 거래 등록
- 내역: 월별 거래 목록, 필터/검색, 추가·수정·삭제
- 통계: 카테고리별 지출/수입, 최근 6개월 추이
- 예산: 카테고리별 월 예산 설정 및 진행률
- 계좌: 현금/계좌/카드 잔액 자동 계산
- 정기거래: 월세·구독료·급여 등 자동 등록
- 설정: 카테고리 관리, JSON 백업(내보내기/가져오기), 전체 초기화

## 데이터
모든 데이터는 이 기기의 브라우저에만 저장됩니다(localStorage). 다른 기기로 옮기려면
설정 탭의 내보내기(JSON) 후 다른 기기에서 가져오기를 사용하세요.
